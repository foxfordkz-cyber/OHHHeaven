## Решения

- **Новое поле — в `extra`.** В `RealWorldPlan` (`shared/src/types.ts`) нет `extra`, файл меняет только ведущий. `realWorldPlan` возвращает `RealWorldPlan & { extra: { personal } }` — это совместимо с типом, хост и сервер передают объект как есть. Клиент повторяет форму в `client/src/screens/end/personal.ts` и проверяет её перед показом: старая ссылка на план без `extra` по-прежнему открывается.
- **Запас.** Раньше запас считался по модели затрат с текущим статусом: у бизнеса в стадии `setup` в него попадала только аренда. Теперь — шесть месяцев честных постоянных расходов работающего кафе (без срезанных углов) в любом статусе.
- **«Деньги до первой продажи»** = предметы по цене этого места + цена готового бизнеса + аренда за дни от подписания до открытия (так её списывает `setupDay`). Других расходов до открытия движок не списывает.
- **Сбережения и отметки — в `localStorage`** (`fy-plan-progress`, ключ — имя бизнеса и адрес). Сервер — не мои файлы. Число сбережений не покидает устройство, на экране так и написано. Просьба к ведущему ниже.
- **Вердикт по сбережениям.** `short` — денег не хватает до первой продажи или после открытия остаётся меньше трёх месяцев постоянных расходов; `thin` — открыться можно, но запас меньше выбранного; `ready` — хватает с выбранным запасом. Месяц расходов = `reserve / reserveMonths` из движка.
- **Поставщики** — порядок и причина по выборам игрока (рычаг `sourcing`, витрина для выпечки, сумма оборудования, страховка из книг, рычаг `pest_control`, сумма ремонта). Связь «поставщик → выбор» пока в коде (`suppliersPart`), сопоставление по id и категории; для других ниш — общий список.

## Находки для других

- **B07 / B11 (важно для показа).** Рекомендованный набор `standard` с `cashLeft ≥ 0` на 3 из 5 проверенных дверей (`ev-0xx` в Ист-Виллидж, аренда $11–16 тыс.) разоряется ДО открытия: `cashLeft` не учитывает аренду за ~81 день ожидания (ремонт 60 дней + разрешение FSE 21 день после ремонта). Пример: 1st Ave между E 13th и E 14th — касса −$1 578 в первом месяце, двери так и не открылись. В личном плане это теперь видно строкой «Rent before the first sale».
- **Закон.** `launch` проходит после конца ремонта, хотя разрешение FSE (`afterBuildout`) ещё ждёт: у бизнеса появляется след `no_fse_permit`. Если это задумано как срезанный угол — игроку стоит это сказать на кнопке.
