## Просьбы к ведущему
- **Реестр крючков.** В `engine/src/niches/index.ts` (файл агента 01) раскомментировать `import { hooks as barbershop } from './barbershop'` и строку `barbershop,`.
- **Доступ к сайтам.** Для проверки чисел по самим страницам нужны хосты: `dos.ny.gov`, `www.tax.ny.gov`, `www.nysenate.gov`, `www.nyc.gov`, `nyc-business.nyc.gov`, `dol.ny.gov`, `www.wcb.ny.gov`, `www.bls.gov`, `codelibrary.amlegal.com`.
- **Sales tax по нишам.** Движку нужна ставка на единицу продажи из пакета ниши: стрижка — 4,5%, товары — 8,875% (`extra.salesTax`). Две строки `taxes` с базой `taxable_revenue` нельзя обе применять ко всей выручке.
- **История штата.** Чтобы уход мастера считался точно, в `BusinessState` нужно число работников на конец прошлого месяца (например `staffPrev: Record<string, number>`). Сейчас крючок выводит его из `history[-1].capacityUnits`; если движок считает `capacityUnits` иначе, чем `min(мастера, кресла) × 30`, порог 7% может дать ложный «уход» на один месяц.
- **Кто стрижёт.** Общая формула `staffCap = Σ работников × unitsPerStaffMonth` считает администратора (`front_desk`) мастером. Прошу агента 02 брать `capacityDay` из крючка, если он вернул число.
- **Розница.** Выручку и себестоимость косметики добавляет `extraLines` при закрытии месяца; собранный с неё sales tax (8,875%) движок не видит. Если нужен точный учёт — нужна вторая «единица продажи» в формате пакета.
