**Переменные, которые задаёт человек** (только на сервере):
- `ANTHROPIC_API_KEY` — ключ Anthropic. Без него всё работает на запасном пути.
- `AI_MODEL` — модель, по умолчанию `claude-opus-5-5`.
- `AI_PROVIDER=mock` — принудительно без сети, даже при наличии ключа.
- `AI_TIMEOUT_MS` — бюджет вызова, по умолчанию и максимум 8000.
- `AI_MAX_RPM` — лимит вызовов в минуту, по умолчанию 20.
- `AI_LOG=1` — печатать журнал вызовов в stderr.
- `AI_DEMO_WEEKS` — сколько недель демо планирует моделью, по умолчанию 4.

## Решения и почему
- **Ветка.** Работаю в `claude/loving-knuth-t4zp49`: её назначила среда сессии.
- **Входы пакета.** `@ohh/ai` — всё, SDK грузится лениво и только при наличии ключа. `@ohh/ai/pure` — только `forecast`, `deckEvent`, `DECK`, `THEMES`: для браузера и режима Practice, хосту в браузере импортировать его.
- **Источник погоды.** Нормы NOAA/NWS: общественное достояние, коммерция разрешена. Open-Meteo не беру: бесплатный API только некоммерческий (open-meteo.com/en/terms).
  - Сеть песочницы закрыта для noaa.gov и weather.gov, поэтому числа взяты из выдачи поиска по страницам NWS.
  - Дождливые дни за 7 месяцев помечены `estimate`; `fetch-climate.mjs` заменит их там, где есть сеть. Против живого API скрипт не проверен.
- **Как строится ряд погоды.**
  - План месяца из норм: число дождливых, снежных, штормовых и жарких дней с вероятностным округлением; жара идёт одной волной.
  - Температура — норма дня плюс AR(1)-отклонение.
  - День зависит только от (seed, day), поэтому любое окно прогноза согласовано.
- **`footTrafficMult`:** ясно 1,0; облачно 1,0 (оценка); дождь 0,9; снег 0,85; жара 0,95 (оценка); шторм 0,7. Источники — в `nyc-climate.json` и отчёте.
- **Колода.**
  - 40 карточек: погода 7, транспорт 7, поставки 9, город 13, правила 3, персонал 1.
  - Повод — проверенный факт со ссылкой, сила эффекта — оценка дизайна для агента 07.
  - Реальные даты (марафон, Pride, неделя ООН, Restaurant Week и др.) переносятся в игровой календарь по номеру месяца и дню. Дни недели из их текстов убраны: игровой календарь с реальным не совпадает.
- **Порядок `deckEvent`.**
  - Только игровые понедельники, не больше одного события в неделю; события ИИ тоже считаются.
  - Сначала события с реальной датой (за 1–2 недели), потом погодное предупреждение, если такая погода есть в прогнозе, потом случайная карточка (в 35% недель — тишина).
  - Повтор темы не накладывается на ту же тему.
- **Карточки правил без эффектов.** Минимальная зарплата, проверки и мусорные баки идут без эффектов: в `EffectTarget` нет целей «зарплата» и «частота проверок».
- **Проверки `planEvents`:**
  - схема; тема и её вид;
  - месяцы темы и сезонные слова (метель в июле отбрасывается);
  - согласие с прогнозом;
  - срок объявления: не раньше `EVENT_NOTICE_DAYS`, не дальше 28 дней;
  - цели и множители (0,7–1,3 и уже по теме);
  - ниши и улицы из входа;
  - запрещённые темы и придуманные суммы или проценты;
  - повтор темы.
- **SDK.**
  - По документации skill `claude-api`: `output_config.format: zodOutputFormat(schema)` и `output_config.effort: "low"`; без `temperature`, без принудительного `tool_choice`, без выключения `thinking`. Схемы на `zod/v4`, как в хелпере SDK.
  - Сначала был `client.messages.parse`, но тест против локального фейка API показал: `parse` разбирает JSON внутри SDK и при отказе модели бросает `AnthropicError` раньше, чем можно прочесть `stop_reason`.
  - Поэтому вызов — `client.messages.create` с тем же форматом (так документация описывает `create`). Сначала проверяю `stop_reason` (`refusal`, `max_tokens`), потом разбираю текст методом `format.parse`.
- **Бюджет вызова.** `maxRetries: 0` и свой таймер 8 с: повтор запроса сломал бы бюджет, а запасной путь есть всегда.
- **Server-side fallbacks** (бета) не включал: бета-вариант с форматом в skill не описан, а отказ модели и так уводит на детерминированный путь.
- **Советник.**
  - Намерение вопроса и карточки пакета ниши и `_common` по совпадению слов.
  - Шаблон считает числа сам: работник = ставка × часы; экономия срезанного угла по `saves.basis`; штраф за 6 месяцев по CONTRACT §5.
  - Ответ ИИ принимается, только если в нём не больше 90 слов, есть число, все числа есть в данных (допуск 3%) и нет поощрения нарушений.
- **Подбор ниши.**
  - Ключевые слова, «сильные» слова считаются вдвое.
  - Ниша без пакета заменяется ближайшей играбельной с пояснением.
  - Числа в заметках только из пакета. Процента про веганское меню нет: источника не нашёл.
- **Разбор.** Потери берутся из `RealWorldPlan.lessons` без изменений. Текст ИИ отбрасывается, если в нём есть число не из данных.
- **Слияние с каркасом агента 01.** `ai/src/index.ts` — мой: заглушку агент 01 оставил для замены. `ai/tsconfig.json` — версия основной ветки плюс папка `test`. Вложенный `ai/package-lock.json` удалён, зависимости ставятся из корня.
