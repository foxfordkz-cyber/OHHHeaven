# r3-B06 — проверка игры в браузере

Исполнитель B06, третий заход. Ветка `claude/exciting-franklin-0zk5x7`. Старт 22:34 UTC 14 ноября.

## Как проверить одной командой

```bash
node scripts/e2e/journey.mjs
```

Сам поднимает сервер на свободном порту (собирает клиент, если нет `client/dist`), проходит путь игрока в браузере на 375 и 1440, пишет `docs/qa/runs/<время>/RUN.md`, `results.json` и снимки. Против выложенной игры: `node scripts/e2e/journey.mjs --url https://<адрес>`.

## Сделано

- 22:50 UTC — каркас `scripts/e2e/journey.mjs`: главная (гость) → идея → место → план → вход → набор → разрешения → открытие. Каждый шаг идёт через интерфейс; если шаг сломан — снимок, запись и обход через API, чтобы проверить остальное.

## Решения

- Каждый прогон создаёт свой демо-город (`POST /api/worlds`) и ставит его часы на паузу: прогон не зависит от того, что уже открыто в общем демо-городе, а дни двигаем сами (`/clock advanceDays`).
- Прогон не останавливается на первой поломке: обход через API. Иначе одна сломанная кнопка прячет все поломки дальше по пути.
