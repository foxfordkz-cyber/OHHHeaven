# r3-B14 — Что продаём: тариф и оплата

Исполнитель B14 третьего захода. Ветка `claude/laughing-goodall-asisbr`.

## Что сделано

- `server/src/billing.ts` — тариф First Year Pro: чистые функции «кто что может» (`entitlement`, `gateAction`, `gateQuery`, `freeEndsDay`), Stripe Checkout в тестовом режиме, маршруты `/api/worlds/:id/billing*`.
- Подключение в сервере — одна строка `mountBilling(app, game)` в `createApp` (`server/src/index.ts`) плюс импорт.
- `client/src/screens/paywall/` — экран `/pro`: что входит, сколько стоит, когда появляется; кнопка оплаты; возврат из Stripe.

## Как проверить

```
npm run check && npm test && node scripts/smoke.mjs
```

Экран на примерных данных: `npm run dev:client` → `/dev/pro`, `/dev/pro-autopilot`, `/dev/pro-setup`, `/dev/pro-paid`.

## Решения (людей не спрашивал)

1. **Когда кончается бесплатное.** Конец первого полного месяца после открытия дверей: открылся на 82-й день → бесплатно до 120-го (месяц 91–120). Игрок видит полный отчёт первого месяца — и в этот момент появляется тариф. Стройка и разрешения бесплатны целиком.
2. **Что закрывается после бесплатного месяца.** Решения управления: `set_orders`, `buy_item`, `sell_item`, `resize`, `spend`. Кофейня не останавливается — работает на последних распоряжениях («автопилот»), игрок видит, как она живёт без него. Это сильнее, чем запрет смотреть.
3. **Что остаётся бесплатным всегда.** Соседские ходы (сделки, ответы на сделки, жалобы, ответы на уведомления, входящие): в них участвует второй игрок, платный не должен ждать бесплатного. Госслужащие — бесплатно.
4. **Личный план** (`real_world_plan`) — только Pro. На экране тарифа бесплатный игрок видит заголовки своего плана из своей игры (сколько нужно до первой продажи, в месяц, в запас; число шагов и поставщиков) — без самих шагов и ссылок.
5. **Советник** — три вопроса бесплатно, дальше Pro. Отступление от задания («советник — платно»): игрок должен попробовать ценность до оплаты.
6. **Все виды бизнеса** — открыть не кофейню (`open_business` с другой нишей) можно только в Pro.
7. **Признак тарифа** — у игрока в `extra.billing` (и счётчик советника в `extra.billingUsage`) внутри мира: переживает перезапуск вместе со снимком. В типе `Player` поля `extra` нет — читаю через локальный тип, в `shared/` не лезу (см. просьбы).
8. **Stripe — только тестовый ключ** (`sk_test_`/`rk_test_`). Боевой ключ игнорируется с записью в лог: на хакатоне настоящие деньги не списываем. Без ключа кнопка открывает Pro сразу и честно пишет «тестовый режим, ничего не списано».
9. **Город показа** (`pitch`, задание A5) без ограничений по умолчанию: `BILLING_OPEN_WORLDS=pitch`. Выключатель всего тарифа: `BILLING_GATE=off`.

## Переменные окружения (задаёт человек)

- `STRIPE_SECRET_KEY` — тестовый секретный ключ Stripe (`sk_test_...`). Без него — тестовое открытие без оплаты.
- `STRIPE_PRICE_MONTH`, `STRIPE_PRICE_YEAR` — необязательно: готовые цены из кабинета Stripe (`price_...`). Без них цена задаётся в запросе.
- `PUBLIC_URL` — необязательно: адрес, на который Stripe вернёт игрока (по умолчанию — адрес запроса).
- `BILLING_GATE=off` — выключить ограничения.
- `BILLING_OPEN_WORLDS` — миры без ограничений через запятую (по умолчанию `pitch`).
