## Решения

1. Сохранена исходная сетка, но пропущенные роли обнуляются явно: иначе `set_orders` оставляет старшего по умолчанию и искажает сравнение.
2. Опорная синтетическая дверь сохраняет прежний спрос 6000 заказов зрелого кафе через расчёт числа прохожих из текущего `captureRate`; цены и зарплаты остаются из пакета. Это оценка стенда, не реальный адрес. Источник и формула в README и метаданных.
3. Двери для разнообразия выбираются по географии, доступности и якорям до симуляции. Офисный/жилой/туристический/кампусный типы — явно помеченные приближения: в `data/places.json` нет измеренных долей гостей, сами адресные записи отмечены `unverified`.
4. Сначала сравнивается полный год новичка; копия проверяется отдельно среди уже работающих кафе через публичный `openEstablished`. Иначе ремонт и раннее банкротство копии не оставляют сопоставимого периода работы. Оригинал в контрольной ветке устанавливается тем же способом.
5. FAIL аудита — полезный результат, а не повод менять критерий. Ошибка запуска получает отдельный код 2. Требование «красное не пушь» трактуется как отсутствие поломок штатных проверок: намеренный FAIL незакрытой дыры B03 необходимо передать исполнителям.
6. Проверка итогового diff обнаружила, что исходная локальная ветка несла также прежние файлы D00, ещё не слитые в основную. Поэтому до передачи ветка G1 пересобрана от актуальной основной с переносом только коммитов G1. Исходная история сохранена в локальной `research/audit-cafe-logic-with-d00`, исследование D00 не удалено и не изменено. Итоговый diff G1 ограничен `sim/audit/` и этим журналом.

## Передача при блокировке push

Полная ветка сохраняется в `/workspace/OHHHeaven-G1-round3.bundle`; это файл передачи вне репозитория. Проверка — `git bundle verify /workspace/OHHHeaven-G1-round3.bundle`. Ведущему доступны все новые файлы и результаты без применения отдельных патчей.

Если bundle скачан в стандартную папку Downloads на Windows, команды для **cmd.exe**, каждая отдельной строкой (новая папка `OHHHeaven-G1` должна быть свободна):

```bat
git clone --branch research/audit-cafe-logic "%USERPROFILE%\Downloads\OHHHeaven-G1-round3.bundle" "%USERPROFILE%\OHHHeaven-G1"
git -C "%USERPROFILE%\OHHHeaven-G1" remote set-url origin https://github.com/foxfordkz-cyber/OHHHeaven.git
git -C "%USERPROFILE%\OHHHeaven-G1" push -u origin research/audit-cafe-logic
```

Команды не зависят от текущей папки терминала. Это обход отсутствия доступа у исполнителя, а не выполненный push.
