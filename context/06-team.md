# Команда, инструменты и правила работы агентов

Записано 14 ноября 2026 в 10:50 UTC со слов пользователя (третья смена ведущего). Правила в разделах 3–5 — решение ведущего, обязательны для всех агентов.

## 1. Люди и инструменты

| У кого | Что есть |
|---|---|
| Пользователь | Claude Max (ведущий, эта сессия в Claude Code на его компьютере), Gemini Pro, GPT Pro |
| Напарник | GPT Pro, Gemini Pro, Claude Desktop |
| Общие | 13 браузерных вкладок Claude (тариф Pro, модель Fable) и 6 запасных аккаунтов Pro |

## 2. Кто что делает (решение пользователя)

- **Ведущий (тимлид)** — Claude Max. Пишет каркас и контракты, раздаёт задания, сводит ветки, дорабатывает.
- **Код пишут 13 браузерных вкладок Claude.** Каждая — в своей ветке `claude/*`.
- **Запасные аккаунты** подключаются, когда у вкладки кончился лимит или сбросилась сессия: новый агент берёт тот же номер и продолжает по журналу (раздел 4).
- GPT и Gemini — исследования, проверка фактов, тексты питча.

## 3. Правила для каждого агента

1. **Своя ветка.** Пишешь только в свою ветку `claude/*`. В основную ветку `claude/global-entrepreneur-product-133cix` пушит только ведущий. Pull request не создавай.
2. **Свои файлы.** Трогаешь только папки, названные в твоём задании. Общие файлы (контракты, типы, `package.json` в корне) меняет только ведущий; нужна правка — напиши её в журнал в раздел «Просьбы к ведущему».
3. **Журнал.** Ведёшь файл `agents/NN.md` (NN — твой номер) в своей ветке. Шаблон — в разделе 5. Журнал обновляется в том же коммите, что и работа.
4. **Коммит и пуш после каждого рабочего шага**, не реже раза в 20 минут. Незакоммиченная работа считается несделанной: лимит может кончиться в любой момент.
5. **Перед началом работы и раз в час** — `git fetch` и `git merge origin/claude/global-entrepreneur-product-133cix` в свою ветку. Конфликт в чужом файле — бери версию основной ветки.
6. **Работает — значит запускается.** В журнале записана команда, которой твою часть можно проверить, и что она выводит.
7. Деньги и исход раунда считает код. ИИ пишет только тексты.

## 4. Как продолжить за агентом, у которого кончился лимит

Промпт для запасного аккаунта: «Ты агент № NN, продолжаешь за предшественником. Репозиторий OHHHeaven. Прочитай `context/FULL.md` и `context/06-team.md` в ветке claude/global-entrepreneur-product-133cix, затем найди ветку с журналом `agents/NN.md` и продолжай с раздела „Следующий шаг“».

Найти ветку предшественника:

```bash
git fetch origin '+refs/heads/*:refs/remotes/origin/*'
git log --all -1 --format='%D' -- agents/NN.md
```

Новый агент вливает ветку предшественника в свою (`git merge origin/<ветка>`) и первым коммитом дописывает в журнал строку «принял работу, время UTC».

## 5. Шаблон журнала `agents/NN.md`

```markdown
# Агент NN — <роль>
Ветка: claude/<имя>. Задание: build/tasks/NN-<имя>.md.

## Состояние (обновлено ЧЧ:ММ UTC)
Что готово и работает. Что начато и не закончено.

## Как проверить
Команда и ожидаемый вывод.

## Следующий шаг
Одно конкретное действие, с которого начнёт сменщик.

## Решения и почему
Короткий список.

## Просьбы к ведущему
Правки общих файлов, вопросы, блокеры.

## Журнал
- ЧЧ:ММ UTC — что сделал, хэш коммита.
```

## 6. Ведущий

- Решения — наверх `HANDOFF.md`. Диалог с пользователем — `context/LOG.md`. Оба файла коммитятся и пушатся после каждого значимого обмена.
- Сменщик ведущего начинает с `context/FULL.md`, затем верх `HANDOFF.md` и конец `context/LOG.md`.
