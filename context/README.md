1. Записать весь контекст в эту папку — сделано.
2. Ведущий задаёт вопросы, которые не может решить сам; решаем вместе — три ответа получены, выбор ниш ждёт.
3. Собрать `FULL.md` — сделано, обновляется после каждого решения.
4. Передать ведение Claude на тарифе Max: он начинает с `FULL.md`.
5. По `FULL.md` писать код и делать сайт.
