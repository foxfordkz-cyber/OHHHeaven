# Агент 08 — Клиент: оболочка, базовый интерфейс, вход и открытие бизнеса

> Зачем: Ты делаешь лицо игры и общие детали интерфейса, которыми пользуются остальные три агента клиента.
> Твои папки: `client/` (корень пакета, `src/app/`, `src/ui/`, `src/screens/onboarding/`)

Прочитай по порядку: `context/FULL.md`, `context/06-team.md`, `build/PROTOCOL.md`, `build/CONTRACT.md`, `shared/src/types.ts`. Затем выполни задание. Людей не спрашивай — решай сам и записывай решения в журнал `agents/08.md`.

## Шаг 1 — основа для остальных (первые 30 минут, затем пуш: её ждут агенты 09, 10, 11)

- Vite + React + TypeScript. `src/app/socket.ts` — типизированный клиент Socket.IO (`ClientToServer`, `ServerToClient`), сохранение `token` в `localStorage`, переподключение. `src/app/store.ts` — стор с последним `ClientView` и хук `useView()`. `src/app/router.tsx` — маршруты из `build/CONTRACT.md`, раздел 7, и `/dev/<screen>` для отладки экранов на примерах. `src/app/fixtures.ts` — правдоподобные примеры `OwnerView`, `OfficialView`, `SpectatorView` для кафе.
- Дизайн-система `src/ui/`: `tokens.css` (тёмная тема, один акцентный цвет, шкала отступов и шрифтов, цвета прибыли и убытка) и компоненты: `Button`, `Card`, `Sheet` (выезжающая снизу панель), `Stat` (крупная цифра с подписью и изменением), `MoneyText`, `Stepper`, `Slider`, `Toggle`, `SegmentedControl`, `Badge`, `ProgressBar`, `Timer`, `ListRow`, `Toast`, `Tabs`, `BottomNav`, `RuleCard` (карточка «Real rule» со ссылкой), `Feed`. Страница `/dev/ui` показывает все компоненты. Выглядит как готовое приложение: без эмодзи вместо иконок (иконки — inline SVG), системный шрифт, ширина 390 без горизонтальной прокрутки.
- В `client/README.md` — как подключить экран и какие компоненты есть.

## Шаг 2 — экраны входа и открытия (`src/screens/onboarding/`)

1. **Вход.** New York City, банк города (растущая цифра), «Season 0 · 7/10 seats», таблица призов, поле имени, «Pay $5 (test) and play», «Play free as a city official» (выбор роли: Inspector, Tax auditor, Journalist), пометка, что деньги в демо тестовые.
2. **Лобби.** Кто вошёл, боты помечены BOT, кнопка «Start season» у первого вошедшего.
3. **Выбор ниши.** Пять карточек из `GET /api/packs`: название, слоган, стартовый капитал, главный проверяющий, сложность. Ниша без пакета — закрытая карточка «Coming soon».
4. **Выбор места.** Слот для компонента карты агента 09 (`<CityMap places onPick />`); до его появления — список мест с адресом, площадью, арендой и потоком.
5. **Открытие — система рекомендует.** Запрос `business:recommend` возвращает три варианта (`lean`, `standard`, `premium`). Игрок видит рекомендованный вариант раскрытым: размер (мест), покупки по группам (мебель, оборудование, разрешения, депозит) с количеством и ценами, итог, остаток кассы и причины `why`. Одна кнопка «Open with recommended setup». Ссылка «Customize» открывает панель, где можно сменить вариант, размер (степпер с пересчётом суммы) и убрать необязательные покупки; обязательные помечены замком и карточкой правила. Название бизнеса — поле с готовым вариантом.
6. Переход на экран хода по `phase`.

## Проверка

`npm run dev -w @ohh/client`: `/dev/ui` и `/dev/onboarding` открываются без сервера на примерах; с сервером агента 06 — проходит вход и открытие. `npm test -w @ohh/client` — тесты стора и компонента открытия.
