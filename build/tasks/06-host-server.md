# Агент 06 — Хост и сервер: город, который идёт сам

> Зачем: Ты делаешь мир, который живёт по своим часам и никого не ждёт, и отдаёшь каждому игроку его картину.
> Твои папки: `host/`, `server/`

Прочитай по порядку: `context/08-game-v5.md` (что за игра), `context/06-team.md` (журнал и ветки), `build/PROTOCOL.md`, `build/CONTRACT.md`, `shared/src/types.ts`, `shared/src/rules.ts`. Затем выполни задание. Людей не спрашивай — решай сам и записывай решения в журнал `agents/06.md`. Никого не жди: чужого куска нет — работай на заглушке и своих примерах данных.

## Часть А — хост (`@ohh/host`, чистый TypeScript, работает и в браузере)

Функции раздела 6 `build/CONTRACT.md`: `newWorld`, `join`, `act`, `step`, `viewFor`, `answer`. Никаких модулей Node: этот же пакет клиент запускает в браузере для игры без сервера.

1. **`newWorld`** — мир из `WorldConfig`; заселение бизнесами и госслужащими под управлением ИИ через `deps.bots.populate` (они открываются теми же `Action`); прогноз погоды на `FORECAST_DAYS`.
2. **`join`** — владелец или госслужащий; вход открыт до месяца `JOIN_UNTIL_MONTH`; тестовый взнос владельца сразу пополняет `bank`.
3. **`act`** — проверка формы действия, роли и прав (владелец управляет только своим бизнесом, госслужащий — только делами своей роли), затем `applyAction` движка; обновляет `lastSeenDay` и `version`.
4. **`step`** — один игровой день: сдвинуть прогноз (`deps.forecast`); раз в игровую неделю добавить событие (`deps.deckEvent`, если очередь событий от ИИ пуста); ходы жителей под управлением ИИ (`ownerActions`, `officialActions`); раз в `MANAGER_REVIEW_DAYS` для бизнесов с `autopilot: 'manager'` применить `managerOrders` (агент 04); `tickDay`; сводки во входящие.
5. **`viewFor`** — `OwnerView`, `OfficialView`, `CityView`. Владелец видит свой бизнес целиком, соседей — только как `PublicBusiness`; госслужащий — `CaseCard` без чужих касс. Блок `away`: если игрок не заходил больше одного игрового дня — сколько дней прошло, сколько заработано, что случилось и что ждёт ответа.
6. **`answer`** — синхронные запросы: `recommend_opening`, `what_if`, `roadmap`, `real_world_plan`.

Чужие пакеты (`@ohh/engine`, `@ohh/bots`) подключаются через один файл `host/src/deps.ts`; пока их нет в основной ветке — заглушки по сигнатурам в `host/src/__stubs__/`.

## Часть Б — сервер (`@ohh/server`, Express)

Маршруты раздела 6 контракта. При старте — два мира: живой `nyc` (`DAY_MS_LIVE`) и `demo` (`DAY_MS_DEMO`).

1. **Часы.** Для каждого мира цикл на `setTimeout`: `step`, затем снимок. Пропущенные дни после перезапуска догоняются (не больше 30 за раз). `POST /api/worlds/:id/clock` — пауза и скорость, только для демо-миров. `WorldPublic.msToNextDay` — чтобы клиент показывал ход времени.
2. **Вход.** `join` выдаёт `playerId` и `token`; токен — в заголовке `Authorization: Bearer`. Тот же токен возвращает игрока в любой момент — мир его не ждал.
3. **`view`** с параметром версии отвечает `{ "unchanged": true }`, если мир не менялся: клиенты опрашивают часто.
4. **Запросы к ИИ** (`advisor`, `idea`, `debrief`) идут в `@ohh/ai`; раз в игровую неделю сервер в фоне зовёт `planEvents` и кладёт результат в очередь событий мира. Расчёт дня ИИ не ждёт никогда.
5. **Данные.** `packs/*.json` и `data/places.json` читаются при старте; нет файла — примеры из `server/fixtures/`.
6. **Надёжность.** Проверка каждого запроса; ошибка в одном мире не роняет процесс; снимки в `server/.snapshots/<id>.json` и восстановление при старте; ограничение частоты запросов на игрока.
7. **Рабочая нагрузка.** 100 владельцев, опрос раз в две секунды — сервер держит без заметной задержки; проверь скриптом.

## Тесты

Хост: мир из 30 жителей проходит 60 дней на заглушках; владелец не получает чужую кассу ни в одном `view`; `away` считается верно. Сервер (supertest): вход, действие, `view`, `unchanged`, возврат по токену через 40 игровых дней, пауза часов.

## Проверка

`npm test -w @ohh/host -w @ohh/server` зелёный; `npm run dev -w @ohh/server` и `npx tsx server/scripts/play.ts`: два скриптовых владельца проходят проверку из раздела 10 файла `context/08-game-v5.md` и печатают итог.
