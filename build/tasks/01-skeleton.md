# Агент 01 — Каркас, склейка и деплой

> Зачем: Ты делаешь каркас проекта и отвечаешь за то, чтобы 13 кусков собрались в одно приложение.
> Твои папки: корень репозитория (`package.json`, `tsconfig.base.json`, `README.md`, `scripts/`, `.github/`), `shared/` (кроме `src/types.ts`), `engine/src/niches/index.ts`

Прочитай по порядку: `context/FULL.md`, `context/06-team.md`, `build/PROTOCOL.md`, `build/CONTRACT.md`, `shared/src/types.ts`. Затем выполни задание. Людей не спрашивай — решай сам и записывай решения в журнал `agents/01.md`.

## Шаг 1 — каркас (первые 20 минут, затем сразу пуш)

- npm workspaces: `shared`, `engine`, `ai`, `server`, `bots`, `client`. В каждом — `package.json` с именем из `build/CONTRACT.md` (`@ohh/…`), `tsconfig.json`, `src/index.ts` с экспортами-заглушками по сигнатурам контракта, один проходящий тест. Чужие папки создаёшь только как пустой каркас; содержимое пишут их владельцы.
- Корневые скрипты: `npm run dev` (сервер и клиент вместе), `npm test` (vitest по всем пакетам), `npm run check` (tsc --noEmit по всем), `npm run build`, `npm start` (сервер раздаёт собранный клиент на одном порту).
- `shared/src/index.ts` реэкспортирует `types.ts`. `shared/src/util/`: `clamp`, `round2`, `sum`, сидируемый генератор `mulberry32` (только для ботов и тестов), `formatMoney`.
- `client`: Vite + React + TypeScript, пустая страница «OK»; `server`: Express + Socket.IO, `GET /api/health`.
- `README.md`: как запустить за три команды.
- В журнале напиши: «каркас запушен, ветка такая-то» — ведущий перенесёт его в основную ветку.

## Шаг 2 — сквозной дымовой тест

`scripts/smoke.mjs`: поднимает сервер, подключает двух владельцев и одного госслужащего по сокету, проходит вход, открытие бизнеса и два месяца, проверяет, что пришёл `view` с `month = 2`. Пока чужих кусков нет — на заглушках. Это главный индикатор проекта: он должен быть зелёным всегда.

## Шаг 3 — склейка (до конца хакатона)

- Каждые 30 минут: `git fetch`, смотри ветки `claude/*` и журналы `agents/*.md`. Готовые куски вливай в свою ветку (`git merge`), чини конфликты и типы, гоняй `npm run check`, `npm test`, `scripts/smoke.mjs`. Свою ветку пушь — ведущий забирает её в основную.
- `engine/src/niches/index.ts`: реестр `Record<NicheId, NicheHooks>`; добавляй импорт, когда вливаешь ветку ниши.
- Веди в журнале таблицу: агент, ветка, что влито, что сломано, что заменить с заглушки на настоящее. Чужой код не переписывай: сломанное описывай в журнале в разделе «Для агента NN» — владелец читает его при слиянии основной ветки.
- `scripts/validate-all.mjs`: прогоняет `build/validate-pack.mjs` по всем `packs/*.json` и проверяет, что каждый пакет приводится к типу `Pack`.

## Шаг 4 — деплой

Один сервис Node, один порт. Подготовь `Dockerfile` и конфигурацию для бесплатного хостинга с WebSocket (Render или Fly.io — выбери по документации и запиши почему), плюс инструкцию запуска с ноутбука в локальной сети как запасной план. Сам ничего не разворачивай и аккаунтов не создавай: это сделает человек по твоей инструкции в `README.md`.

## Проверка

`npm install && npm run check && npm test && node scripts/smoke.mjs` — всё зелёное на чистом клоне.
