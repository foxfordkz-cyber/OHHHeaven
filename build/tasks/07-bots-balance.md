## Часть А — боты (`@ohh/bots`)

```ts
export function fillSeats(s: SeasonState, ctx: EngineCtx, seed: number): { owners: { name: string; niche: NicheId; placeId: string; strategy: string }[]; officials: { name: string; role: OfficialRole }[] }
export function botDecisions(s: SeasonState, ctx: EngineCtx, businessId: string, seed: number): MonthDecisions
export function botOfficialDecisions(s: SeasonState, ctx: EngineCtx, officialId: string, seed: number): OfficialDecisions
```

- Стратегии владельцев: честный; срезает всё; срезает только налоги; срезает и предлагает взятку; жалобщик (атакует лидера); демпингующий; премиальный. Основа — `research/reports/52-bots-spec.md` и `28-bots-ghosts.md`. Бот видит только то, что видел бы человек на его месте.
- Чиновники: идёт по жалобам; идёт по подозрительным цифрам; берёт взятки с порога; честный.
- Случайность — только через сид (`mulberry32` из `@ohh/shared`). Имена ботов — вымышленные, с пометкой BOT в интерфейсе (поле `isBot`).
- Бот открывает бизнес через `recommendOpening` агента 04 и не разоряется в первые три месяца на честной стратегии.

## Часть Б — симулятор (`sim/season.ts`)

`npx tsx sim/season.ts --niche cafe --owners 20 --officials 3 --seasons 1000 --seed 1` гонит сезоны на настоящем движке и печатает таблицы. Пока движка нет в основной ветке — работай на его текущей версии из ветки агента 02 (`git fetch`, смотри `agents/02.md`), а до неё — на собственной упрощённой копии формул контракта в `sim/__stubs__/`.

Вопросы, на которые отвечает отчёт `research/reports/07-balance.md` (на каждый — таблица и решение, какое число поменять и в каком файле):
1. Доля побед и банкротств по стратегиям. Цель: ни одна стратегия не берёт больше 35% сезонов; «срезает всё» разоряется чаще честного; умеренное срезание выгодно при слабом контроле и убыточно при сильном.
2. При каком числе проверок в месяц нарушать перестаёт быть выгодно (от 1 до 6).
3. Сколько честных новичков разоряется за сезон. Цель — 15–30%; подбери `startCapital`.
4. Какой множитель `pctOfSaved` делает зарплату наличными игрой с нулевым ожиданием при трёх проверках.
5. Окупается ли жалоба и не выгодно ли всем травить лидера.
6. Размер зала: кривая прибыли от числа мест для трёх ярусов мест — есть ли внутренний оптимум, а не «чем больше, тем лучше».
7. ИИ-события: насколько события с множителями 0,7–1,3 меняют места в таблице (исход должен решать игрок, а не погода).

По мере появления настоящих пакетов в основной ветке (`packs/*.json`) прогоняй каждый и пиши в журнал в раздел «Для агента NN», какие числа ломают баланс.

## Тесты

Одинаковый сид — одинаковый сезон; бот не шлёт недопустимых решений (свойство на 500 случайных состояниях); честный бот не банкрот за три месяца.
