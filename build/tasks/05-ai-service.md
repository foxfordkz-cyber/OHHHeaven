# Агент 05 — ИИ: события города, погода, советник и разбор

> Зачем: ИИ ведёт город: погода, бури, пробки и цены, отвечает игроку на вопросы о бизнесе и объясняет в конце, на чём он потерял деньги.
> Твои папки: `ai/`, `research/reports/05-ai.md`

Прочитай по порядку: `context/FULL.md`, `context/06-team.md`, `build/PROTOCOL.md`, `build/CONTRACT.md`, `shared/src/types.ts`. Затем выполни задание. Людей не спрашивай — решай сам и записывай решения в журнал `agents/05.md`.

## Что сделать

Пакет `@ohh/ai` с функциями `planEvents`, `getWeather`, `askAdvisor`, `writeDebrief` из `build/CONTRACT.md`, раздел 5. Правила раздела 5 обязательны: никогда не бросать исключение, ответ не дольше 8 секунд, без ключа всё работает на запасном пути.

### 1. Провайдер

- Claude через официальный SDK `@anthropic-ai/sdk`. Модель — из переменной `AI_MODEL`, по умолчанию `claude-opus-5-5`; ключ — `ANTHROPIC_API_KEY`, только на сервере. Перед тем как писать вызовы, прочитай актуальную документацию SDK (в Claude Code — skill `claude-api`): структурированный ответ через `output_config.format` (`client.messages.parse` со схемой), `tool_choice` с принуждением не использовать, `thinking` и `temperature` не задавать, глубину регулировать `output_config.effort: "low"`, проверять `stop_reason` (в том числе `refusal`) до чтения ответа. Имена методов не угадывай.
- `AI_PROVIDER=mock` или отсутствие ключа — запасной путь без сети. Интерфейс провайдера один, чтобы другой сервис подключался одним файлом.
- Кэш ответов по хэшу входа; лимит запросов в минуту; журнал вызовов без ключей.

### 2. `getWeather` — настоящая погода Нью-Йорка

Игровой месяц равен календарному (месяц 1 — январь). Собери климатические нормы Нью-Йорка по месяцам из открытого источника (NOAA NCEI или Open-Meteo Climate/Historical API — проверь условия использования и запиши в отчёт) в `ai/src/data/nyc-climate.json`: средние максимум и минимум, дни с осадками, снег. Файл лежит в репозитории, сеть в игре для погоды не нужна. Скрипт обновления — `ai/scripts/fetch-climate.mjs`.

### 3. `planEvents` — ИИ ведёт события

На вход — месяц, погода, недавние события, ниши, запасная колода пакетов. На выход — одно или два события типа `GameEvent` на следующий месяц: погода (метель, жара, ливень, ураганное предупреждение), транспорт (пробки, закрытая ветка метро, перекрытая улица), поставки (кофе, молоко, энергия), город (уличная ярмарка, марафон, туристический пик), правила (новая кампания проверок). ИИ выбирает, что случилось, пишет заголовок и два предложения по-английски и назначает эффекты только из белого списка `EffectTarget` с множителем 0,7–1,3 и фильтрами по нишам и ярусам мест. Ответ проверяется схемой; невалидный — берётся событие из колоды. Событие должно быть правдоподобным для этого месяца в Нью-Йорке (метель в июле запрещена — проверка по нормам). Ничего о гибели людей и катастрофах. Составь запасную колоду `ai/src/data/deck.json` из 40 событий с настоящими поводами и источниками (отчёт `research/reports/44-event-deck.md` — основа).

### 4. `askAdvisor` — «Ask the advisor»

Игрок задаёт вопрос своими словами («Should I hire a third barista?», «What happens if I pay cash wages?»). В запрос к модели идут: числа бизнеса и аналитика, карточки правил и нарушения из пакета ниши и `_common` (отбери подходящие по словам вопроса), и требование отвечать только по этим данным, до 90 слов, с числом и со ссылками на использованные карточки. О нарушениях советник говорит честно: сколько это экономит и чем грозит по закону; уклоняться не подталкивает. Запасной путь без ИИ — поиск по карточкам правил и ответ шаблоном (`origin: 'rules'`).

### 5. `writeDebrief` — разбор сезона

Числа считает код: возьми из истории бизнеса три самые дорогие потери (штрафы, потерянные продажи, переплата за аренду или людей, потраченный налог) — это `lostMoneyOn` с суммами. ИИ пишет только заголовок, урок к каждой потере и советы на следующий сезон. Запасной путь — шаблоны.

## Тесты

Все четыре функции на mock-провайдере; таймаут и ошибка провайдера → запасной путь; невалидный ответ модели → колода; событие с множителем 3 обрезается; метель в июле отбрасывается. Тесты не ходят в сеть.
