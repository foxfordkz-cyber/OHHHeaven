# Исследователь 71 — Проверка фактов в пакетах ниш

> Кому: Claude (вкладка с доступом к репозиторию) · веб-поиск обязателен
> Зачем: Ловит неверные числа до того, как их увидит жюри: в прошлой проверке 12 из 52 цифр оказались неверны.

Прочитай по порядку: `context/FULL.md`, `context/06-team.md`, `research/WAVE4.md`, `build/PACK.md`. Затем выполни задание.

## Задание

```text
ЦЕЛЬ: research/reports/71-fact-check-packs.md и исправленные пакеты. Запускается, когда в ветках появились packs/*.json (исследователи 61–66). Нет ни одного — жди 15 минут и проверь снова; пока ждёшь, проверь числа в context/02-questions.md (часть Б, пункты 6–13) и context/05-niches.md.

ПОРЯДОК:
1. git fetch всех веток; найди самые свежие packs/*.json (git log --all -- packs/).
2. Для каждого пакета открой КАЖДУЮ ссылку source у строк с confidence = verified в taxes, violations, staff, затем в setup и monthlyCosts. Сверь число, год, применимость к Нью-Йорку и к малому бизнесу.
3. Вердикт по строке: OK / НЕВЕРНО (верное значение и ссылка) / ССЫЛКА НЕ ОТКРЫВАЕТСЯ / ИСТОЧНИК НЕ ПРО ЭТО / УСТАРЕЛО.
4. Сверь пакеты между собой: одна и та же ставка (минимальная зарплата, sales tax, payroll) должна совпадать во всех файлах и в _common.
5. Исправленные версии положи в свою ветку по тем же путям packs/<id>.json (менять можно только числа, ссылки, confidence и note); прогони валидатор.
6. Здравый смысл: посчитай P&L честного владельца по каждому пакету; если прибыль за месяц больше 40% выручки или убыток при средней цене — пометь как подозрительное и назови строку-виновника.

ОТЧЁТ: таблица по каждому пакету (строка, было, стало, вердикт, ссылка), счёт «проверено N, неверно M», список чисел, которые нельзя показывать жюри.

ЧЕК-ЛИСТ СДАЧИ:
- Проверены все строки taxes и violations во всех найденных пакетах.
- Каждое «НЕВЕРНО» — с первоисточником.
- Исправленные пакеты проходят валидатор.
```
