# Исследование идеи — Business Cup 2.0, трек ENTERTAINMENT

20 исследователей, у каждого своё задание. Задания лежат в этой папке, исследователь находит своё по номеру.

## Универсальный промпт

Вставляется в любую вкладку, подключённую к репозиторию. Меняется только номер в первой строке.

```text
Ты исследователь № 07.

Репозиторий OHHHeaven, ветка claude/global-entrepreneur-product-133cix. Прочитай там файл research/CONTEXT.md, затем найди в папке research/prompts/ файл, имя которого начинается с твоего номера, и выполни задание из него.

Если в твоей копии репозитория этих файлов нет, сначала подтяни ветку: git fetch origin claude/global-entrepreneur-product-133cix
```

- Номера 01–14 запускаются сразу и работают параллельно.
- Номер 15 (синтезатор) — когда пришли ответы. Если отчётов нет в репозитории, вставь под промптом блоки «=== ИТОГ ===» из чатов.
- Номера 16–20 — резерв на вторую волну. Под промптом вставь выбранную идею (для 20 — ещё и идею напарника).
- Gemini не подключён к репозиторию: ему вставляется готовый текст из `full/02-gemini.md`. Запасной полный текст для GPT — `full/01-gpt.md`.
