# Проверка игры в браузере (B06)

Как проверяется, что First Year работает от первого экрана до личного плана, и что нашли за ночь 14–15 ноября.

## Одной командой

```bash
node scripts/e2e/journey.mjs
```

Путь нового игрока в Chromium на телефоне (375 px) и компьютере (1440 px): главная → идея → место → план → вход → карточки решений → разрешения → открытие → шесть вкладок → прогноз цены и «Apply» → «Your change» на следующий день → совет → правка при идущих часах → сделка → ответ на входящее предложение → жалоба → стол инспектора → возвращение (`/brief`) → месяц → конец бесплатного месяца и Pro → конец сезона → личный план. Каждый шаг — через интерфейс, со снимком, проверкой горизонтальной прокрутки, ошибок страницы и консоли и ответов 5xx. Подробно — `scripts/e2e/README.md`.

| Команда | Что проверяет |
|---|---|
| `scripts/e2e/cycle.sh <ветка>` | тот же путь на свежей сборке любой ветки (отдельная рабочая копия) |
| `node scripts/e2e/first-minute.mjs` | первая минута на телефоне при идущем демо-городе, в секундах |
| `node scripts/e2e/perf.mjs` | скорость первого экрана на телефоне со слабой сетью и на компьютере |
| `node scripts/e2e/pitch-show.mjs` | пятиминутный показ жюри в четырёх браузерах (телефоны Maya и Viktor, проектор, пульт) |
| `scripts/e2e/prod.sh https://<адрес> [ключ]` | всё это против выложенной игры |
