Снято: 14 ноября, 23:16 UTC, сборка сборщика B04 `4b76a07` (в ней B07, B08, B13, B14, B18). Демо-город, часы на паузе («City paused» в шапке), деньги тестовые, оплата Pro — тестовая без списания. Числа на снимках — из игры на момент прогона, их никто не правил. Имена игроков — Jordan (игрок), Sam's Cuts (сосед), Dana (инспектор); остальные кофейни — ИИ-жители, они так и помечены «AI».
