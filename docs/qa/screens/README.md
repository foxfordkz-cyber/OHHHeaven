# Снимки экранов для презентации (B06)

Настоящие экраны игры, снятые прогоном `node scripts/e2e/journey.mjs --shots docs/qa/screens` в Chromium: телефон 375×812 и компьютер 1440×900, ×2 (retina), то, что видно на экране без прокрутки. 256 цветов, чтобы файлы были лёгкими.

Снято: 14 ноября, 22:45 UTC, сборка `ac5a14d`. Демо-город, часы на паузе («City paused» в шапке), деньги тестовые. Числа на снимках — из игры на момент прогона, их никто не правил. Пересниму после слияния клиентских веток (B07, B08, B09, B18) у сборщика B04.
