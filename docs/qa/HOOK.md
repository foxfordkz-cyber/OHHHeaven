## Первая минута в цифрах

`node scripts/e2e/first-minute.mjs` — новичок на телефоне, демо-город идёт сам (один игровой день ≈ 2 с), 3 секунды на чтение каждого экрана, берёт предложенное. Полная лента — `FIRST-MINUTE.md`.

| | Секунд от входа |
|---|---|
| первое решение (идея, «See my plan») | 3,6 |
| первое число в ответ («Opening here costs from $127,779 of your $224,000») | 9,9 |
| аренда подписана | 22,3 |
| «Open doors» включилась | 84,2 |
| первая продажа на экране (Orders sold 131) | 90,4 |

- Это на быстрой сети. **На телефоне с медленной сетью (Slow 4G, `perf.mjs`) поле идеи появляется только через 12,9 с** — до первого решения игрок 13 секунд смотрит на загрузку (`BUGS.md`, №11).
- **8 решений за первые 22 секунды, потом 62 секунды без единого решения** (самый длинный отрезок без решения — 65 с). Жюри смотрит на экран ожидания разрешений, где можно только ждать или «Open early».
- До первой продажи игрок ни разу не видит, **заработает ли он**: все числа до открытия — про траты (стоимость открытия, остаток, аренда). Первая цифра прибыли появляется на Today после открытия, и она отрицательная (прогноз месяца −$5 000).
- Соперник с именем впервые появляется только во вкладке Network.

## Что больше всего мешает затянуть с первой минуты

1. **Минута пустого ожидания после подписания аренды.** Предложение B07 (`WaitStep.tsx`): пока идут разрешения — решения, которые в жизни принимают именно сейчас: цена первой чашки, сколько бариста нанять к открытию, поставщик, часы. Проверено пробой через API (22:59 UTC): `set_orders` в статусе `setup` движок принимает (цена 8,50 → 9,00 сохранилась). А `what_if` в `setup` считает текущий месяц, когда кафе закрыто: «served 0, profit −$32 323» — прогноза первого месяца работы до открытия нет. Нужна просьба к ведущему (журнал B06): `what_if` для первого месяца после открытия. Пока её нет, B07 может показать решение и его цену в месяц (зарплата, стоимость рычага), без прогноза продаж. И ход соседа: кто рядом открылся и по какой цене (лента `feed`).
2. **Рекомендация игры проигрывает по расчёту самой игры** (`BUGS.md`, №1). Игрок, который следует советам, получает минус с первого месяца и #12–#15 из 16 к концу сезона. Причины вернуться завтра нет, если каждый день — потеря без понятного выхода.
3. ~~Нет соперника с именем.~~ В сборке B04 есть: лестница во вкладке Network и соперник на `/brief` (B18, B13). На Today его по-прежнему нет — а это первый экран, который игрок видит каждый день.
4. **На телефоне поле идеи ниже сгиба** (`BUGS.md`, №5): первое решение начинается с прокрутки.
